# Калькулятор: тренажёр

Тренажёр проводит ученика от создания папки до публикации на GitHub: рабочий стол → VS Code → HTML → CSS → JavaScript → git → GitHub. Всё происходит внутри тренажёра, ничего устанавливать не нужно. Код ученик набирает сам по образцу, тренажёр проверяет и подсказывает, где ошибка.

- `index.html` — тренажёр для учеников
- `index.html?teacher` — режим преподавателя: комментарии к шагам, «Подставить ответ», переход к любому шагу
- `metodichka.html` — методичка для печати: все шаги, код, комментарии, итоговый код

Шаги и файлы калькулятора описаны в `steps.js`, движок — `app.js`.

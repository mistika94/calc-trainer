3Что с чем связано

Файлы находят друг друга по именам. Если имя в одном месте отличается хотя бы одной буквой — связь не работает. Совпадающие имена выделены жёлтым.

В index.html написаноЧто это находит
<link rel="stylesheet" href="style.css">
внутри <head>		→подключает файл style.css. Без этой строки оформления не будет.
<script src="script.js"></script>
в самом низу, перед </body>		→подключает файл script.js. Без этой строки кнопки не нажимаются.
<div class="buttons">→в style.css: .buttons { … } — точка значит «класс»
<input id="display">→в style.css: #display { … } — решётка значит «id»
в script.js: document.getElementById('display')
<button onclick="pressDigit('7')">7</button>→в script.js: function pressDigit(digit) { … } — при нажатии запускается эта функция, digit получает '7'
class — имя группы, может быть у многих элементов. id — личное имя, на странице он только один. Большие и маленькие буквы — разные: clearAll и clearall не одно и то же.

4HTML — структура

Тег — слово в угловых скобках. Почти всегда парный:

<button>7</button>
открывающий  текст  закрывающий (со слешем)
<head>служебная часть, на странице не видна
<body>всё, что видно на странице
<title>надпись на вкладке браузера
<h1>заголовок
<div>коробка для других элементов
<input>поле (экран калькулятора), закрывать не нужно
<button>кнопка

Что внутри коробки — пишем со сдвигом вправо (Tab). Так легче увидеть, что где лежит.

6JavaScript — логика

let a = 0;переменная — коробочка с именем, в неё положили 0
function имя() { … }функция — команды с именем; работает, только когда её вызовут
onclick="имя()"вызвать функцию, когда нажали кнопку
display.valueто, что сейчас написано на экране
Number('12')превращает текст '12' в число 12
=положить в коробку
===сравнить: «равно ли?»
if (…) { … }если условие верно — сделать
else if (…)а иначе если…
'текст'текст всегда в кавычках

Почему нужен Number: '12' + '30' даст '1230' (текст склеился), а 12 + 30 даст 42.

Кавычки в onclick: снаружи двойные, внутри одинарные — onclick="pressDigit('7')".

7Git — команды по порядку

Терминал открыт в папке проекта. Команды — маленькими буквами, после каждой Enter.

Один раз на компьютере

git config --global user.name "Ivan Petrov"
git config --global user.email "ivan@mail.ru"

Первая отправка проекта

  1. git init — Git начинает следить за папкой
  2. git add . — выбрать все файлы (точка — «всё»)
  3. git commit -m "Мой калькулятор" — сохранить снимок с подписью
  4. создать репозиторий на GitHub (справа)
  5. git branch -M main — назвать ветку main
  6. git remote add origin https://github.com/логин/calculator.git — куда отправлять
  7. git push -u origin main — отправить

Потом, после каждой правки

git add .
git commit -m "что изменил"
git push

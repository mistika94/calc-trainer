Тренажёр «Калькулятор на HTML, CSS и JavaScript»

Методические указания для преподавателя

1. Назначение тренажёра

Тренажёр проводит ученика по всему пути создания веб-приложения: от создания папки проекта до публикации на GitHub. Все действия выполняются внутри тренажёра: он изображает рабочий стол Windows, редактор VS Code, браузер, терминал и сайт GitHub, поэтому устанавливать программы не нужно, а заниматься можно и дома.

Код ученик набирает сам по образцу — по одной-две строки за шаг. Тренажёр проверяет набранное и подсказывает, где ошибка: регистр букв, русская раскладка, незакрытая кавычка или скобка, пропущенная точка с запятой. Повторяющиеся части (остальные кнопки, второстепенные свойства CSS, остальные ветки условия) робот дописывает сам и объясняет, что добавил.

2. Как пользоваться

КомуСсылка и возможности
Ученикуindex.html — имя, логин GitHub (необязательно), дальше шаги по порядку. Прогресс сохраняется в браузере; кнопка ↺ — начать заново. Вставка кода из буфера отключена: код набирается руками.
Преподавателюindex.html?teacher — к каждому шагу комментарий, кнопка «Подставить ответ», точки шагов в шапке кликабельны (переход к любому шагу), вставка разрешена. Ссылка сразу на шаг: index.html?teacher#step=jsCalc (идентификаторы шагов — в таблице ниже).

Управление: Enter — проверить строку; в многострочных шагах Enter — новая строка, Ctrl+Enter — проверить, Tab — отступ; после верного ответа Enter — следующий шаг.
